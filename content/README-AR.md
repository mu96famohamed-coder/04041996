# كتابة المقالات من ملف واحد

الملف الذي تُضيف وتُحرر فيه المقالات هو **content/articles.json** فقط. مجلد content موجود في جذر المشروع بجانب app وcomponents وdata؛ لا تضعه داخل public.

هذا الملف يحتوي جميع المقالات الـ18 الحالية، بنصوصها وترجماتها وتواريخها وعناوينها ووصف SEO كما كانت. قوالب العرض والتصميم ما زالت في مكانها ولم تتغير.

## إضافة مقال

1. افتح articles.json بمحرر مثل VS Code.
2. أضف عنصرًا جديدًا داخل الكائن الرئيسي، بمفتاح جديد مثل your-new-article-slug. لا تُغيّر مفاتيح المقالات القديمة؛ المفتاح هو الجزء الأخير من الرابط.
3. اكتب عناوين المقال ووصفه وترجماته ومحتواه في العنصر نفسه. لا تُكرر اسم الموقع في title_*؛ القالب يضيف اسم العلامة إلى عنوان SEO بالطريقة الحالية.
4. ضع تاريخ النشر الحقيقي في date، وتاريخ التعديل الحقيقي في date_updated، بصيغة YYYY-MM-DD. لا تغيّر تواريخ المقالات القديمة لمجرد تعديل الكود أو النقل.
5. احفظ JSON صحيحًا، ثم نفّذ npm run build وانشر التحديث بالطريقة المعتادة. الملف ليس لوحة تحكم تُحدّث الموقع المنشور فور الحفظ؛ كل إضافة تحتاج إعادة بناء ونشر.

بعد ذلك تُكتشف الإضافة تلقائيًا في قائمة المدونة، وتوليد صفحة المقال باللغات الخمس، والسيت ماب وlastModified الخاص بالمقال، وcanonical وhreflang وArticle Schema. لا تحتاج تعديل app/sitemap.ts أو أي قائمة روابط يدويًا للمقال الجديد.

## الحقول

| الحقل | الاستخدام |
|---|---|
| مفتاح المقال، مثل your-new-article-slug | رابط ثابت: /en/blog/your-new-article-slug/، وبالمثل للغات الأخرى |
| title_en, title_ar, title_ru, title_zh, title_es | عنوان المقال في كل لغة، ويستخدمه القالب أيضًا لعنوان SEO |
| meta_en, meta_ar, meta_ru, meta_zh, meta_es | الوصف في كل لغة |
| date | تاريخ النشر بصيغة YYYY-MM-DD |
| date_updated | تاريخ آخر تعديل حقيقي، ويمكن أن يساوي تاريخ النشر |
| rich_blocks | فقرات وعناوين المقال وترجماتها؛ يمكن تكرار heading وpara بحسب الحاجة |
| faq | الأسئلة الشائعة للمقال؛ اتركها [] عند عدم وجود أسئلة |
| related | مفاتيح المقالات المرتبطة، وليس روابط كاملة |

title_en مطلوب لاكتشاف المقال بصورة سليمة. الأفضل تعبئة جميع اللغات الخمس؛ سلوك الرجوع للإنجليزية عند غياب ترجمة بقي كما كان. استخدم مفتاحًا فريدًا بحروف إنجليزية صغيرة وأرقام وشرطات، ولا تستخدم اسم مسار محوّل في next.config.mjs.

## نموذج للنسخ

هذا مثال توضيحي فقط، وليس مقالًا مضافًا للموقع. أضف العنصر الداخلي داخل كائن articles.json الموجود بالفعل، مع الفاصلة اللازمة بين المقالات. لا تستبدل الملف كله بهذا المثال، ولا تضف كائنًا رئيسيًا ثانيًا.

```json
{
  "your-new-article-slug": {
    "title_en": "New article title",
    "meta_en": "Short description of the new article.",
    "title_ar": "عنوان المقال الجديد",
    "meta_ar": "وصف موجز للمقال الجديد.",
    "title_ru": "Заголовок новой статьи",
    "meta_ru": "Краткое описание новой статьи.",
    "title_zh": "新文章标题",
    "meta_zh": "新文章的简短描述。",
    "title_es": "Título del nuevo artículo",
    "meta_es": "Descripción breve del nuevo artículo.",
    "date": "2026-10-18",
    "date_updated": "2026-10-18",
    "rich_blocks": [
      {
        "type": "heading",
        "text": {
          "en": "Section title",
          "ar": "عنوان القسم",
          "ru": "Заголовок раздела",
          "zh": "章节标题",
          "es": "Título de la sección"
        }
      },
      {
        "type": "para",
        "text": {
          "en": "Write the article paragraph here.",
          "ar": "اكتب فقرة المقال هنا.",
          "ru": "Напишите здесь абзац статьи.",
          "zh": "在此撰写文章段落。",
          "es": "Escribe aquí el párrafo del artículo."
        }
      }
    ],
    "faq": [],
    "related": [
      "how-to-get-poa-dubai"
    ]
  }
}
```

لإضافة فقرات أخرى كرر عنصر para داخل rich_blocks. للفصل بعناوين كرر heading. جميع المقالات الحالية ما زالت تدعم تنسيقها السابق، بما فيه h2 وcontent وlist_items وfaq وrich_blocks؛ لم نُعد كتابة محتواها.

لا تستخدم تعليقات JavaScript في JSON، ولا تترك فاصلة بعد آخر عنصر. لا تكرر مفتاحًا موجودًا: تكراره قد يستبدل مقالًا قديمًا في محلل JSON.

## حماية الروابط الحالية

يوجد فحص يمنع نجاح البناء إذا اختفى مفتاح أحد المقالات الحالية، أو كان مفتاح مقال غير صالح، أو كان title_en فارغًا، أو كان التاريخ غير صالح. هذا يمنع نشر حذف أو تغيير عرضي لرابط قديم. لا تغيّر قوائم الحماية في lib/articles.ts عند إضافة مقال عادي.

## حالة السيت ماب التي حُفظت

قبل النقل كان ملف البيانات يحتوي 18 مقالًا، لكن قائمتي توليد الصفحات الثابتة والسيت ماب كانتا تحتويان 16 فقط. المقالان التاليان كانا يظهران في قائمة المدونة ويعملان عند فتح رابطهما، دون إدراج في السيت ماب:

- poa-cancellation-dubai-revoke
- special-power-of-attorney-uae-guide

حُفظت هذه الحالة كما هي، بناءً على طلب عدم تغيير قواعد الفهرسة الحالية أثناء نقل التخزين. لم تُحذف روابطهما ولم تُضَف توجيهات أو noindex. جميع المقالات الجديدة المضافة بمفاتيح جديدة تُضاف تلقائيًا للتوليد والسيت ماب. تغيير حالة المقالين القديمين عمل منفصل عن عملية النقل هذه.
